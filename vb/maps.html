MAPS

Voidborn Rift is the official arena: two tiered home asteroids, a central Eye and islands of ore, built for flying monsters. Around it is a whole family of arenas – the map repository with its own statistics, previews and downloads.

Where the maps come from. Voidborn Rift is part of the game repository (dist/voidborn_rift.sd7). The rest live in the BAR-Maps repository, which holds the archive, a minimap and a documentation file for each one. Drop a .sd7 into the maps/ folder of your engine data directory and it shows up in the map list of the game – no rebuild of the game needed.

Using a map

Copy the archive into the maps/ folder of your engine data directory (for a Flatpak install of BAR that is usually ~/.var/app/info.beyondallreason.bar/data/engine/<version>/maps/), then start the game and pick the map in the map chooser. The start scripts that come with the game point at Voidborn Rift; change the MapName line to play on another one.

Voidborn Rift

The official map: a shattered void of floating asteroids with a central Eye, two tiered home asteroids per side and islands of ore to expand into. Two to four players.

Cosmic Spaceship

A drifting chromatic spaceship in the cosmos, with geothermal weapon pods and reclaimable kryptonite. Small, tight and fast.

Yin-Yang

A circular arena between ice crystals, two players, two metal spots each. The smallest map in the family.
